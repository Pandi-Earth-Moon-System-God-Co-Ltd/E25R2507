# 创作工坊 · 5 分钟上手

> 给不写代码的同事：所有内容都在游戏里点出来，不用改任何文件。

## 打开

1. 双击 `index.html` 开始游戏；
2. 游戏中按 **F2**（开始界面 / 暂停菜单里也有「创作工坊」按钮）；
3. 顶部标签切换模块：物品 / 方块 / 机器 / 技能 / 地图 / 蓝图 / 角色 / 音画 / MOD。

界面分三栏：**左边内容列表 · 中间编辑 · 右边实时预览**。底部固定「保存 / 清空 / 返回游戏」。

## 三个最省事的操作

| 操作 | 怎么做 | 适合 |
|---|---|---|
| **从模板开始** | 点「从模板开始」里的 chips（材料/食物/武器/机器…），字段自动预填 | 第一次做内容 |
| **复制为新内容** | 列表里点 **⧉**，整份复制成「副本」，ID 自动改成 `_copy` | 做同类变体（改几个数值就是新东西） |
| **撤销** | 顶栏 **↶ 撤销**，最近 30 步 | 改坏了想回退 |

## 每个模块填什么

### 物品
- **内容 ID**：唯一标识，建议 `studio:名字`，只允许字母数字 `_ - :`，**保存后别改**；
- **名称/描述**：显示在背包提示框；
- **物品类型**：材料 / 食物 / 武器 / 工具 / 护甲 —— 选哪个就出现对应的数值栏；
- **主色/阴影色**：没有贴图时用它画图标；
- **贴图**：上传 PNG（自动压成 32×32），保存后图标就是这个图；
- **制作配方**：右下「＋ 添加材料」，摆 3×3 格子，填每次产出与所需科技。

### 方块
ID / 名称 / 描述 / 掉落物 / 硬度 / 颜色 / 贴图。保存后自动进合成表（木板 4 个）。

### 机器
- **机器 ID** 与 **机器方块 ID** 是两个东西（方块是它放下后的样子）；
- **燃料物品 / 每批燃料**：烧什么、一次几份；
- **加工配方**：`输入 → 产物`，加 `数量`、`耗时(秒)`、`耗电`，可加多条；
- **机器界面**：标题、状态、各栏文字、底色/强调色/文字色。

### 技能
ID / 名称 / 说明 / 战斗效果（spin dash wave ward nova）/ 等级要求 / 技能经验 / 体力 / 冷却 / 前置技能。

### 地图
- **绘制地图**：选地形笔刷（草地/森林/岩石/洞穴/水域/沙地/雪地）在画布上点/拖；
- 物件笔刷（树木/岩石/浆果/饮水点/宝箱/遗迹/洞穴入口）画在格子上，再点一次擦除；
- **出生点**笔刷；「随机地形」可一键生成；
- **世界规则**：种子、一天秒数、每季天数、饥饿/口渴/敌袭倍率、初始食物与水。

### 蓝图 / 角色 / 音画 / MOD
蓝图是创意草稿（生物/事件逻辑）；角色改外观；音画调音乐音效；MOD 页负责导出/导入与团队信息。

## 保存前

顶部会实时提示：ID 缺失、ID 被占用、名称空、配方材料无效、机器配方为空等。**把红色提示清空再保存**。

## 分享给同事

「MOD」页 → **导出 MOD 包**（一个 JSON，含全部内容与贴图）→ 发给同事 → 对方在 **导入 MOD 包** 里选文件。

## 常见问题

- **改了贴图没生效？** 保存物品后才会写入；图标缓存按 ID 存，换 ID 就是新图标。
- **机器放下没反应？** 看熔炉界面底部的电压提示，可能「电压不足」，需要先研究对应科技或放一台变压器。
- **内容删不掉/改错？** 列表行 **×** 删除；改错用 **↶ 撤销**。
- **想批量做类似的？** 用 **⧉ 复制**，别重复填表。


## 进阶：写自定义技能效果（会一点 JS 的话）

1. 打开 `mods/sample-effects.js`，里面已有两个例子（黑洞 / 冰环）；
2. 复制一段，改个 ID 和名字：

```js
registerSkillEffect('myBurst', {
  name: '我的爆发',
  cast(ctx){
    // ctx.player / ctx.enemies / ctx.damage / ctx.angle
    // ctx.particles(x, y, 颜色, 数量)
    // ctx.hit(敌人, 下标)  ← 对某个敌人造成本次技能伤害
  },
});
```

3. 保存后刷新游戏，**创作工坊 → 技能** 的「战斗效果」下拉里就会出现「我的爆发」；
4. 到游戏里按 Z/X/V/B 释放即可；伤害倍率/作用距离还是可以在编辑器里调。

> 注意：效果是函数，不能被导出进 MOD 包。要让同事也能用，把 `mods/` 下的脚本一起发给他们，或在 `index.html` 里引入。
