## 2. 企画の背景・目的

プレイヤーが自然環境の中で資源を集め、道具や設備を作りながら生活するサバイバルゲームを制作する。食料・水分・体力などの管理と、探索・クラフト・成長を組み合わせ、短いプレイの中でも目標を見つけられる体験を目指す。

また、ゲーム内の「Game Studio」とMod APIを通じて、マップやアイテム、ブロック、機械などを追加・編集できる仕組みを用意し、プレイヤーが遊ぶだけでなく創作にも参加できるゲームを目指す。

## 3. 想定する利用者

- サバイバルゲームやクラフトゲームに興味がある人
- ブラウザーですぐに遊べるゲームを探している人
- マップやアイテムなどのゲームコンテンツ制作に興味がある人

## 4. ゲームの概要

プレイヤーはワールドを探索し、木材・石・食料などを集める。集めた素材で道具や設備を作り、空腹・水分・体力に注意しながら生活範囲を広げていく。昼夜や季節、天候の変化、敵や洞窟などの要素を通じて、探索と準備に意味を持たせる。

## 5. 主な機能

| 分類 | 内容 |
|---|---|
| ワールド | バイオームや川を含むワールド、地上・地下の探索 |
| サバイバル | 空腹・水分・体力の管理、昼夜・季節・天候 |
| 採集・クラフト | 素材の採集、アイテム・道具・設備の作成 |
| 農業・動物 | 作物の栽培、動物の成長・餌やり・繁殖 |
| 村・取引 | 村人とのアイテム売買 |
| 成長要素 | 戦闘などで経験値を獲得し、スキルを習得 |
| セーブ | オートセーブ、複数の手動セーブ、データの入出力 |
| コンテンツ制作 | Game Studioでのマップ・アイテム・機械などの編集 |
| 拡張 | Mod APIによるアイテム、レシピ、ブロック、作物、機械などの登録 |

## 6. 操作・画面

- タイトル画面からゲーム開始、セーブ管理、言語設定、ヘルプ、Game Studioを利用する。
- ゲーム画面ではキーボード・マウスによる移動や操作を行う。
- 操作方法の詳細は、ゲーム内ヘルプに合わせて記載する。

## 7. 制作方針・使用技術

- HTML、CSS、JavaScriptを用いたブラウザーゲームとして制作する。
- ゲームロジックを機能ごとのJavaScriptファイルに分け、HTMLから所定の順序で読み込む。
- Canvasを使ってゲーム画面を描画する。
- セーブデータや制作したコンテンツは、ゲーム内の保存・入出力機能を利用する。

## 12. 想定される課題と対策

| 課題 | 対策 |
|---|---|
| 機能が多く、完成までに時間がかかる | 基本の探索・採集・クラフトを優先し、追加機能は優先順位を付けて実装する |
| 複数の担当機能を統合したときに不具合が出る | ファイルの読み込み順や共有データの扱いを確認し、早い段階から結合テストを行う |
| セーブデータや追加コンテンツの互換性が崩れる | 変更時に既存データの読み込みと新規データの保存を両方テストする |
| 操作やゲームの目的が伝わりにくい | ゲーム内ヘルプとチュートリアル相当の説明を見直す |

## 13. 今後の展望

プレイテストで得た意見をもとに、ゲームバランスや操作性を改善する。追加コンテンツの制作・共有をしやすくし、継続的に遊べるゲームを目指す。
