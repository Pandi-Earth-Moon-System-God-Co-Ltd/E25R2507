# 开发路线

| 里程碑 | 状态 | 验收范围 |
| --- | --- | --- |
| P0 技术基线 | 已有可玩原型 | 角色模型和镜头、森林营地、住宅和洞穴进出、存档及备份恢复 |
| P1 初次近战 | 已接入原型 | 一件近战武器、一种敌人、格挡闪避、胜败、旧档兼容 |
| P1 生存闭环 | 开发中 | 食物、饥饿、休息、负重和演示路线 |
| P2 探索与 RPG | 待开发 | 伙伴、魔法轮盘、遗迹、地牢、死亡袋 |
| P3 四季与世界 | 待开发 | 季节规则、种植、体温、区域生态、叙事和随机事件 |

P1 下一批把已有营火与洞穴战斗接到食物和休息。优先用一个可采集食材、一份营火菜谱和一处可休息的营地落点，走通采集、战斗、返回、烹饪、恢复及重进游戏。之后增加背包格和负重，把出生装备和岩洞奖励纳入同一清单。

当前开放问题包括正式发布平台、随机事件深度、材料和伤害数值，以及跨设备性能目标。完整玩法、优先级和验收标准见 [游戏设计总文档](../../3D_生存动作RPG_游戏设计总文档_GDD_v0.1.md)。
