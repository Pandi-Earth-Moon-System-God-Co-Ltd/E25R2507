# 荒野营地项目说明

荒野营地是单人 3D 开放世界生存动作 RPG。玩家从废弃营地起步，探索、采集和战斗，再返回营地制作和整备。正式设计还包括影响作物、体温和生态的四季、最多三名 AI 伙伴以及可选主线。

## 当前试玩路线

1. 从营地沿小路拾取两份木材和一份石块。
2. 靠近工作台按 `F` 制作引火工具，再到火塘按 `F` 点火。
3. 向林地西侧前往石隙洞穴，在入口按 `F`。靠近石室深处会遇到孢甲虫。
4. 用鼠标左键或 `J` 挥斧，按住 `R` 面向敌人格挡，按空格闪避。击败孢甲虫后可继续采集洞内石块，再原路返营。
5. 森林另一侧的小屋也可独立进入。按 `F5` 保存，按 `F9` 读取，进出场景及重要操作会自动保存。

战斗倒下时会回营并恢复生命，用品和采集进度继续保留。当前洞穴战斗只有一只敌人，环境为固定秋季。动态季节、完整饥饿与体温、伙伴、可找回死亡袋和主线属于后续里程碑。

本机开发基线为 Godot 4.8 beta 3，兼容渲染器和 Windows 键鼠。运行命令与完整键位见 [试玩说明](../README.md)。
