## 企画の目的

廃営地から出発し、森や洞窟を探索して資源を集め、拠点へ持ち帰って次の行動に備えるゲームを作る。季節ごとの気候・生態・作物の変化が、探索先や装備、備蓄を決める理由になる。クラフトとアクション戦闘の両方を楽しみたいプレイヤーを想定する。

## ゲーム内容

| 要素 | 企画内容 |
| --- | --- |
| 探索と準備 | 探索、採集、戦闘、帰還、制作の繰り返し。自然洞窟と攻略用ダンジョンを設ける。 |
| 戦闘 | 近接攻撃、ガード、回避。敵の予備動作を見て距離とタイミングを選ぶ。 |
| サバイバル | 四季が作物、体温、生物の活動に影響する。 |
| 仲間 | 最大 3 人の AI 仲間を勧誘できる。 |
| 物語 | 行方不明の遠征隊と四季の守護者を調査できる。メインストーリーの進行は任意。 |
| 視点 | 斜め見下ろしと一人称に対応する。 |

## 制作計画と評価

| 段階 | 成果物と評価 |
| --- | --- |
| P0 | 森の拠点、小屋と洞窟、移動、両視点、セーブと復旧を検証する。 |
| P1 | 採集、クラフト、点火と近接戦闘が一つのプレイで行える試作を作る。次に食料、休息、所持品を追加する。 |
| P2 | RPG の成長、魔法、仲間、遺跡探索を加える。 |
| P3 | 四季、農耕、地域の生態とシナリオを拡充する。 |

新規データでキャンプに到着し、素材を集めて火を起こし、洞窟で敵を倒して戻る。再起動後に進捗と保存場所が一致することを確認する。制作、素材管理、実機検証の担当はメンバー確定後に記入する。
