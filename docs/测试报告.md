# 测试报告

当前验收环境为 Windows、Godot 4.8 beta 3 和兼容渲染器。运行 `.\survival-p0\play.ps1 -Verify` 进行重新导入和两组无界面回归。

| 回归 | 检查范围 |
| --- | --- |
| 营地 | 移动与动画、镜头、采集、制作、点火、小屋进出、洞穴进出、落点和写入失败恢复 |
| 近战 | 敌人巡逻、追击与预警，键盘和两种视角下的鼠标挥斧，格挡、闪避，重进场景避免敌人叠在玩家身上，击败保存、玩家倒下和旧存档升级 |

本轮在 Intel UHD Graphics 上用 1280×720 窗口完成了两种视角的实机截图检查。[斜俯视战斗](../preview/combat.png) · [第一人称战斗](../preview/combat-first-person.png)

2026-11-24 最终结果为营地无界面回归 24/24，近战无界面回归 16/16，近战带窗口回归 18/18（含两张截图写入检查）。

手动体验时从营地步行进入洞穴，用三种战斗输入完成一次遭遇，然后回营并重开程序。需要留意两种视角下的命中时序、敌人回避和互动提示的位置。跨设备性能、长期存档压力测试和完整生存流程属于后续验收。
