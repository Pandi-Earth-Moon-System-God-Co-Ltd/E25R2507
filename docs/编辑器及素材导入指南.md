# Godot 4.8 编辑器及素材导入指南

在工作区根目录运行 `.\survival-p0\play.ps1 -Editor`，会打开随工作区附带的 Godot 4.8 beta 3 和荒野营地工程。也可在项目管理器中导入 `survival-p0/project.godot`，然后按 `F5` 运行。编辑器中修改场景时，营地、室内和洞穴是独立 `.tscn`，当前地形和道具由场景脚本摆放。

## 引擎内下载素材

1. 在 Godot 编辑器顶部打开 **Asset Store**（资产商店）。首次访问时，可按商店提示选择 **Go Online**。
2. 打开候选素材的详情，查看作者、许可、可用文件和兼容版本。需要的内容可以下载，下载结束后会打开安装配置窗口。
3. 在安装配置中选择当前场景所需文件。先确认压缩包中的文件路径，再把模型、贴图及其许可证整理到该素材对应的 `assets/` 子目录。
4. 在项目中打开导入模型，检查贴图、单位、动画名和根节点。把素材放进实际使用的场景，按 `F5` 看尺寸、穿模和效果，并登记来源和使用位置。

[Godot 官方编辑器内 Asset Store 使用说明](https://docs.godotengine.org/en/4.7/community/asset_store/using_in_editor.html)

本次近战所需的斧、孢甲虫和音效均可从工作区现有素材获得。后续补充可采集食材、烹饪成品和相应动作时，可以从商店或已有素材库选取，入库记录沿用 [素材清单](../ASSETS.md)。
