# 荒野营地

单人 3D 开放世界生存动作 RPG 的 P1 试玩原型。玩家从废弃营地醒来，采集木材、石块并制作引火工具，可以探索林间小屋，也可以带斧进入石隙洞穴与孢甲虫交战。

## 试玩

从工作区根目录的 PowerShell 启动。首次运行会导入本地素材。

```powershell
.\survival-p0\play.ps1
```

加 `-Editor` 可直接打开工作区附带的 Godot 4.8 beta 3 和项目。也可在编辑器中导入 `survival-p0/project.godot` 并按 F5。当前使用兼容渲染器，正式发布平台和随机事件深度待定。

| 操作 | 键位 |
| --- | --- |
| 移动、奔跑 | `WASD` 或方向键，`Shift` 奔跑 |
| 斜俯视镜头 | `Q` / `E` 或按住鼠标右键拖动旋转，滚轮缩放 |
| 切换第一人称，鼠标观察 | `V` |
| 挥斧 | 鼠标左键瞄准挥砍，`J` 按角色朝向挥砍 |
| 格挡、闪避 | 按住 `R` 面向敌人格挡，空格按移动方向闪避 |
| 拾取、制作、点火、进入或离开场景 | `F` |
| 保存、读取 | `F5` / `F9` |
| 打开或关闭操作指南 | `F1` |

拾取、制作、点火、进出场景和战斗胜败会保存进度。存档包含位置、库存、火塘、生命和敌人击败状态，兼容原先的 P0 存档。最新一份损坏时会尝试读取上一份。玩家战斗倒下时回到营地并恢复生命。
