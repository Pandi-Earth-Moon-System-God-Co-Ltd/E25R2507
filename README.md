# Pixel Survival 项目说明

这是由五人团队共同开发的浏览器像素生存游戏，核心入口为 [index.html](./index.html)。
团队共同设计并制作了一款融合“探索 + 生存 + 生产 + 扩展”的 3D 体素生存游戏，并将内容创作能力（地图、道具、流程、技能、机器、Mod）整合进同一套游戏框架中；画面可以在 3D 体素引擎与 2.5D 像素引擎之间切换。

## 1. 项目定位

- 类型：浏览器 3D 体素生存游戏（可切换 2.5D 像素渲染）
- 开发方式：五人团队协作开发
- 运行方式：直接用浏览器打开 HTML 文件即可运行，无需构建工具链
- 技术栈：HTML + CSS + JavaScript + Canvas 2D + WebGL（自研体素渲染器，零第三方依赖）
- 核心价值：团队协作完成可玩的游戏本体，并提供内容编辑与模组扩展能力
- 设计特征：既有生存系统，又有自动保存/读档能力，还具备画面/性能设置、Game Studio 与 Mod API，可扩展内容与玩法

## 2. 团队开发说明

本项目由五名成员共同开发。团队围绕游戏设计、功能实现、内容制作、模块整合和测试完善等工作进行协作；各成员的实际姓名与具体负责内容应以团队分工和个人工作报告为准，本说明不预设个人分工。

项目采用按功能拆分代码的方式，便于成员分别开发和检查相关模块。完成各部分后，需要共同确认脚本加载顺序、共享游戏状态、存档兼容以及游戏内的整体运行效果。

## 3. 核心玩法概览

玩家在世界中进行生存与探索，游戏循环通常包括：

1. 收集资源：木材、石头、食物、矿石、水源等
2. 制造与升级：制作工具、建筑、机器、装饰与设施
3. 管理状态：监控饥饿、水分、体力与健康
4. 探索世界：地面、洞穴、河流、生物群落、敌人与资源分布
5. 发展文明：建立村落、与村民交易、解锁技能与提升战斗能力
6. 扩展创作：利用 Game Studio 或 Mod API 增加新内容

## 4. 主要功能模块

### 4.1 世界探索与地图系统

- 包含地面、洞穴、河流、森林、山地、沙漠、雪地等不同 biome
- 支持生成地图和编辑地图
- 支持日夜循环、季节、天气变化和环境风险
- 地下洞穴与地表环境连接，增加探索深度

### 4.2 生存系统

- 饥饿值、水分值、体力值等核心状态
- 昼夜变化、季节与天气影响游戏环境
- 需要通过采集、烹饪、饮水、休息等方式维持生存
- 资源管理和环境压力构成游戏的挑战来源

### 4.3 采集与制造

- 采集木材、石头、植物、食物与资源材料
- 合成链参考《我的世界》：原木 → 木板 → 木棍 → 工作台 → 工具 / 护甲，以及熔炉、煤炭、铁器、荧晶等层阶
- 合成界面改为《我的世界》式摆放：工作台是 3×3 网格（`C` 打开），背包里还有 2×2 快速合成格
- 有形状的配方（剑、镐、护甲、工作台、熔炉等）需要按格摆放；无序配方把材料放进任意格子即可
- 右侧「配方手册」（JEI 风格）会列出全部配方与所需材料，点击即可自动把材料摆进格子
- 鼠标左键拿起整组、右键拿一半；点击产物格取走成品，`Shift` + 点击可连续制作
- 工具、护甲与机器需要在工作台附近合成（放置工作台后靠近即可）
- 熔炉可烧制木炭、烤熟生肉、冶炼铜/铁、烧开河水
- 支持多种 item、block、recipe 的组合和扩展
- 机器与工业流程可进一步提升生产效率

### 4.4 农业与动物系统

- 支持作物种植与生长
- 作物成长受光照、水分、季节和天气影响
- 包含动物养殖、喂养、繁殖等内容
- 通过调度和资源投入进行小型生态经营

### 4.5 村庄与交易

- 设有村庄与 NPC / 村民系统
- 可通过交易进行物品买卖
- 形成“资源采集—生产—贸易”的循环

### 4.6 成长与技能系统

- 杀敌、打怪、探索等行为获取经验值
- 通过技能树解锁新能力
- 提供装备、战斗、移动、耐力等不同增益
- 技能可通过 Game Studio 编辑与扩展

### 4.7 存档与数据管理

- 自动保存功能
- 支持多份手动存档
- 支持导入/导出存档内容
- 保存数据与地图配置可持续保留并复用

### 4.8 自定义内容与扩展系统

- 上手文档：[docs/编辑器使用说明.md](./docs/编辑器使用说明.md)（给不写代码的同事）\n- 接口文档：[docs/Mod-API-参考.md](./docs/Mod-API-参考.md)（给会写 JS 的同事）

- 创作工坊（全新编辑器）：顶部切换模块，左侧内容列表可搜索 / 新建 / 编辑 / 删除，中间卡片式编辑，右侧实时预览
- 支持物品、方块、机器（含加工配方与机器界面）、技能、地图、生物 / 逻辑蓝图、角色外观、音画设置与 MOD 包管理
- 卡片按「图标与名称 / 数值设定 / 制作配方 / 加工配方 / 世界规则」拆分，保存条固定在窗口底部
- 地图工坊可直接绘制 56×56 世界（地形笔刷、资源笔刷、出生点），并实时预览缩略图
- 内容创建后立即写入本地内容库（Mod API），可在游戏内合成、放置、解锁
- 支持导出 / 导入 JSON MOD 包，方便备份与团队共享
- 适合学习“游戏内容扩展”与“模组开发”思路

### 4.9 渲染引擎与画面设置

- 默认使用自研 WebGL 3D 体素渲染引擎（[js/render3d.js](./js/render3d.js)），零第三方依赖
- 保留原有 2.5D 等距像素渲染（[js/render.js](./js/render.js)），可随时切换
- 世界以 16×16 区块缓存为实例化方块，移动时只重建新区块；整帧通常只有 2 个绘制调用
- 生物、树木、机器、房屋、玩家均由方块模型拼装，带走路/攻击/摇摆动画
- 光照：太阳方向光 + 火把点光源 + 烘焙环境遮蔽；软阴影会随太阳方向偏移，另有日光暖色 / 夜晚冷色 / 镜头暗角
- 第三人称树冠挡住镜头时自动半透明淡出；第一人称不做淡出，靠近树木也是实心
- 按 `F5` 在第三人称 / 第一人称之间切换：第一人称会锁定鼠标，移动鼠标转动视角，`Esc` 释放鼠标
- 按 `L`（或主菜单 / 暂停菜单的“画面与性能”）打开设置面板
- 3D 地形图集使用 `2233/` 材质包里的方块贴图（草地、泥土、石头、沙子、雪、水、原木、树叶、木板、金属、荧晶等）
- 说明：Game Studio 上传的自定义贴图会覆盖物品图标；3D 模组方块仍以物品配色区分

### 4.10 材质包与界面风格

- 物品图标、方块图集、容器界面都取自 `2233/` 材质包（《我的世界》风格贴图）
- 方块类物品（木头、木板、石头、工作台、熔炉、各种机器）在背包 / 快捷栏 / 合成格中显示为等距 3D 小方块
- 背包为《我的世界》原版物品栏布局：4 个防具槽、角色预览、2×2 合成格、3×9 背包与快捷栏
- 合成台为原版工作台布局：3×3 摆放格 + 产物格 + 右侧配方手册
- 鼠标悬停在物品上会显示《我的世界》式提示框：物品名称、属性、说明与操作提示
- 面板、按钮、物品槽、状态条、菜单背景统一为《我的世界》配色（浅灰容器 + 黑色描边 + 深色按钮）
- 贴图以 data URL 内嵌在 [js/mc-textures.js](./js/mc-textures.js)，因此直接双击 `index.html`（file://）也能显示材质包
- 游戏音效从 `2233/` 的 GregTech 音效里提取（攻击、采集、进食、合成、机器、洞穴等），内嵌在 [js/mc-sounds.js](./js/mc-sounds.js)
- 材质包内容有更新时，运行 `python tools/build-mc-textures.py` 重新生成贴图文件

### 5.1 JS 模块职责概览

从脚本加载顺序来看，游戏逻辑分为以下几个关键模块：

- core.js：核心基础逻辑和全局状态（物品、配方、科技）
- theme.js：Minecraft 风格 UI 主题（面板 / 按钮 / 物品槽 / 提示框 / 泥土背景）
- mc-textures.js：材质包贴图（自动生成，物品图标 / 方块图集 / 容器 GUI）
- graphics.js：画面与性能设置（画质预设、分辨率、渲染距离、FPS 上限、自动降质、第一/第三人称）
- world.js：世界生成与地图管理
- player.js：玩家状态、行动、属性与控制
- update.js：更新循环与状态刷新
- render3d.js：WebGL 3D 体素渲染引擎（地形区块、实体模型、光照、投影/拾取、第一人称相机）
- render.js：渲染分发（3D / 2.5D）、世界与屏幕效果
- hud.js：界面显示、状态栏、快捷栏与背包界面
- crafting.js：合成系统（3×3 工作台 / 2×2 背包合成 / 配方手册 / 物品拿放）
- skills.js：技能树与能力系统
- village.js：村庄与交易
- growth.js：成长与经验系统
- save.js：存档管理
- mod-api.js：Mod 接口暴露
- studio.js：内容注册 / 校验 / 导入导出的数据层
- editor.js：创作工坊界面（列表 + 卡片编辑 + 实时预览）
- settings-panel.js：画面与性能设置面板
- startup.js：启动入口

此外还包含 input.js、panels.js、guns.js、tooltip.js、item-icons.js 等辅助模块，用于输入、面板、道具图标、提示和互动支持。
画面设置面板通过 `window.PixelGfx` 读写设置，3D 引擎通过 `window.Pixel3D` 对外暴露投影、拾取、视角与渲染接口。

## 6. 项目特点

### 6.1 适合浏览器运行

项目没有复杂构建流程，直接打开入口文件即可启动。适合课堂作业、原型开发、演示展示和快速迭代。
3D 引擎需要 WebGL 与实例化绘制支持；若浏览器不支持，游戏会自动回退到 2.5D 像素渲染，不影响游玩。

### 6.2 高度可扩展

不仅是一个可玩的游戏，本项目还提供：

- 角色外观编辑
- 物品/方块/机器定制
- 地图编辑
- 技能节点配置
- 音效与视觉资源导入
- 模组注册与内容包导出

这使其具备“游戏本体 + 内容创作平台”的双重定位。

### 6.3 团队开发成果与学习价值

本项目是五人团队协作完成的游戏作品，也体现了多人共同开发前端游戏时的模块划分、功能整合与测试协作。项目内容可用于：

- 学习 HTML5 Canvas 游戏开发
- 学习 WebGL 实例化渲染与体素世界构建
- 练习 JavaScript 模块化设计
- 探索生存游戏系统架构
- 研究 mod / content pipeline
- 进行原型开发和玩法实验

## 7. 运行方式

1. 打开项目根目录中的 [index.html](./index.html)
2. 在浏览器中直接运行，页面将加载游戏主逻辑与界面
3. 如需调试和自定义内容，可打开开发者控制台
4. 如需体验 Mod，可以将 [Pixel_Survival_Plus_Mod_API_Example.js](./Pixel_Survival_Plus_Mod_API_Example.js) 中的示例代码粘贴到控制台执行

### 7.1 画面与性能设置

按 `L`（或点击主菜单 / 暂停菜单中的“画面与性能”）打开设置面板：

| 设置项 | 说明 |
|---|---|
| 渲染引擎 | 3D 体素（WebGL）/ 2.5D 像素（Canvas）实时切换 |
| 画质预设 | 流畅 / 均衡 / 高清 / 极致，一次调整分辨率、视距、光照、粒子 |
| 观察视角 | 等距 45° / 正面 / 侧面 / 俯视；3D 下按住鼠标中键拖动可旋转，Shift+滚轮缩放 |
| 第一人称 | 与 `F5` 同步，切换后锁定鼠标，移动鼠标转动视角 |
| 分辨率 | 1×～4× 内部渲染分辨率（像素画风保持最近邻放大） |
| 渲染距离 | 10～48 格，决定同时加载的区块数量 |
| 粒子密度 | 0～200%，同时影响天气与粒子数量 |
| FPS 上限 | 不限 / 30 / 60 / 120 / 144 |
| 动态光照 | 火把、熔炉、玩家的点光源 |
| 接触阴影 / 水面动画 / 水体渲染 | 低配设备可逐项关闭 |
| 远景雾 | 关闭 / 轻雾 / 中雾 / 浓雾 |
| 帧率不足自动降质 | 连续低帧时自动降低分辨率 → 视距 → 光照，避免卡顿 |
| 瞄准吸附（3D） | 鼠标靠近敌人时自动吸附，便于战斗 |

设置保存在浏览器本地（`pixel-survival-graphics`），与存档、音画设置互不影响。

## 8. 注意事项

- 本项目没有完整的脚本构建流程，直接以浏览器方式运行即可
- 游戏脚本按顺序加载，若添加或调整 JS 文件，需同步检查 [index.html](./index.html) 中的脚本顺序
- Mod API 不是安全沙箱，解析和执行脚本时必须只加载可信内容
- 自定义内容和 Mod 可能会影响游戏状态和存档兼容性，需注意版本更新时的兼容性

## 10. 总结

Pixel Survival 是五人团队共同开发的像素生存游戏，包含：

- 可运行的游戏本体
- 可切换的 3D 体素 / 2.5D 像素双渲染引擎
- 可调的画质与性能设置（含自动降质）
- 参考《我的世界》的合成与工具层阶
- 可扩展的内容编辑器
- 可接入的 Mod 系统
- 可学习的前端/游戏开发结构

项目将可玩的游戏内容与 Game Studio、Mod API 等扩展能力结合起来，体现了团队在游戏设计、程序实现、内容制作与功能整合方面的协作成果。
