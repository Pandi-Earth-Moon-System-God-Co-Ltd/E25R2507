像素生存
这是一个基于浏览器的像素生存游戏项目，核心入口是 index.html。

项目概览
类型：2.5D 浏览器生存游戏
技术栈：HTML + CSS + JavaScript + Canvas
目标：探索世界、收集资源、制造工具与设施、管理饥饿/口渴/体力，并扩展自定义内容
特色：支持 Game Studio、Mod API、地图/物品/机器/技能编辑
主要功能
世界探索：地面、洞穴、河流、生物群落等
生存系统：饥饿、水分、体力、昼夜、季节、天气
采集与制造：木材、石材、食物、工具、设备
农业与动物：种植、饲养、繁殖
村庄与交易：与村民进行商品买卖
成长系统：打怪获得经验值并解锁技能
存档系统：自动保存、手动存档、导入/导出
自定义内容：Game Studio + Mod API
目录说明
index.html 入口文件
CSS/ 游戏样式
js/ 游戏逻辑模块
assets/ 音乐与特效资源
Pixel_Survival_Plus_Mod_API.mdMod API 说明
Pixel_Survival_Plus_Mod_API_Example.jsMod 示例
企画书_グループ.md 团队企划书
作业報告書_個人.md 个人工作报告
运行方式
用浏览器打开 index.html
如果需要调试自定义内容，可在页面加载后打开开发者控制台
如需体验 Mod，可把 Pixel_Survival_Plus_Mod_API_Example.js 中的代码粘贴到控制台执行
注意事项
本项目没有完整的脚本构建流程，直接用浏览器打开即可运行
Mod API 不是安全沙箱，务必只加载可信脚本
如果修改脚本顺序或新增 JS 文件，请注意维护 HTML 里脚本加载顺序
说明
此项目具备“游戏本体 + 玩法扩展 + 创作工具”的结构，适合用于浏览器游戏开发、游戏内容创作原型和模组开发学习。
